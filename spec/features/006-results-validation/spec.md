# 006-results-validation — Especificación

**Estado:** aprobado para SDD 1.0 salvo elementos marcados PENDING/PROPOSED.  
**Historias:** HU14

## Objetivo

Presentar resultado técnico de generación/validación de forma comprensible.

## Reglas y comportamiento

- Mostrar compiled, executed, passed, valid y failureType.
- Distinguir fallo de plataforma de prueba inválida.
- Mostrar errores/log resumen sin saturar; detalle expandible.

## Fuera de alcance

- No ampliar a capacidades no mencionadas en esta spec.
- No convertir decisiones PENDING en implementación definitiva sin aprobación.
